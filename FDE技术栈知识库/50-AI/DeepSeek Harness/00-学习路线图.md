# DeepSeek Harness 从零到一学习路线图

> [!abstract] 目标
> 让一个**零编程基础**但**用过 Agent 工具**的人，从第一性原理理解 DeepSeek Harness 的架构，并具备开发能力。

---

## 你会学到什么

学完这个系列，你能：

- 理解 Agent 工具（如 Claude Code、Cursor、DeepSeek Harness）**内部在做什么**
- 看懂 DeepSeek Harness 的 54 个源码包各自的作用
- 自己动手写一个**最小版本的 Agent**（Python 版）
- 理解"插件系统"、"事件驱动"、"ReAct 循环"等核心架构概念
- 具备阅读和修改 Harness 源码的基础能力

## 如何使用这个指南

1. **按顺序阅读**：每篇都建立在前一篇的基础上
2. **不要跳过代码**：即使看不懂，先混个眼熟，后面会解释
3. **动手实践**：第 15 篇有完整可运行代码，一定要跑一遍
4. **反复查阅**：附录 A 术语表可以随时回来查
