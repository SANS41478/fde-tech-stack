# 国内云

> [!abstract] 定位
> 国内主流公有云：**阿里云、腾讯云、火山引擎（字节）、华为云**。它们技术能力不弱于国际三大，之所以不在「AWS/GCP/Azure」清单里，主要是**市场地理边界与合规**，不是技术优劣。与 [[云平台]] 互补，按「用户在哪里」选择。

---

## 一、为什么常只提 AWS/GCP/Azure

- 起步最早、生态最成熟（AWS 2006 率先商用），英文技术资料默认以它们为范本。
- 全球覆盖（海外上百可用区），做出海 / 国际业务绕不开。

---

## 二、国内四家怎么选

| 云 | 核心优势 | 典型场景 |
| --- | --- | --- |
| **阿里云** | 国内份额第一、产品成熟、中文文档好 | 国内业务首选 |
| **腾讯云** | 游戏、社交、音视频、微信生态打通 | 社交 / 视频 / 小程序 |
| **火山引擎** | 视频 / 推荐 / AI / 大数据强，性价比高（字节后来者） | 音视频、AI 重 |
| **华为云** | 政企、国企、信创、自研软硬件 | 政府 / 央企 / 信创 |

---

## 三、国际三大 vs 国内云的差异维度

- **合规与数据驻留**：国内业务数据常需留在境内，且要能备案（ICP）。国内云天然满足。
- **延迟与付款**：国内云对国内用户延迟低、人民币结算、备案方便。
- **服务模型同构**：国内云同样提供 IaaS/PaaS/FaaS（见 [[云服务模型]]）：ECS≈EC2、OSS≈S3、RDS≈RDS、函数计算≈Lambda、ACK≈EKS。

> [!tip] FDE 策略
> 用户在国内 → 国内云更优；出海 / 全球 → 国际三大。本质是按「地域 + 合规」选，不是「技术高低」选。

---

## 四、大模型服务（部署相关）

- **直接调 API（不自建）**：阿里云百炼、腾讯混元、火山方舟、百度千帆、智谱、Kimi、DeepSeek 等，按 token 计费，最主流。
- **自部署开源模型**：租 GPU（阿里云 GPU / 华为昇腾云），或用托管推理平台（硅基流动、火山方舟推理、阿里 PAI），按 GPU 时长 / token 收费。
- 选型：验证期 / 小流量 → 直接 API；量大且成本敏感 / 数据不出域 → 自部署开源模型。详细成本见 [[LLM API]]。
